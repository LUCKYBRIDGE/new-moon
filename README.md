# New Moon — 달에서 살아남기

NASA Moon Survival 계열 활동의 핵심인 **개인 판단 → 모둠 합의 → 전문가 비교**를 교실용 웹 경험으로 재구성한 프로젝트입니다.

## 현재 1차 구현

- 조난 상황 도입
- 학생 / 모둠 정보 입력
- 15개 물품 개인 순위 결정
- 15개 물품에 대한 반복적인 이유 작성 제거
- 선택형 전문 역할 확장(개인 판단 이후 제공)
- 모둠 최종 순위 작성
- 개인 순위와 모둠 순위 차이가 큰 물품 후보 자동 제시
- 전문가 판단을 보기 **전** 의미 있는 한 물품의 판단 변화 이유 기록
- 변화가 거의 없을 경우 `끝까지 유지한 판단` 성찰로 자동 전환
- 전문가 순위와 설명을 15개 순차 브리핑
- 개인 / 모둠 / 전문가 판단 비교
- 고전식 순위 차이 합계는 접힌 참고 정보로만 제공
- 로컬 자동 저장
- 키보드로 사용 가능한 순위 이동 버튼
- 모바일 대응 및 브라우저 확대 허용

## 실행

```bash
npm install
npm run dev
```

검증:

```bash
npm test
npm run build
```

빌드 결과는 `dist/`에 생성되며 정적 호스팅이 가능합니다.

## 제품 원칙

학생이 전문가 순위에 가까운 숫자를 맞히는 것보다 다음 질문에 답할 수 있게 하는 것을 우선합니다.

> 나는 왜 처음에 그렇게 판단했으며, 어떤 근거 때문에 생각을 바꾸었거나 유지했는가?

전문가 순위는 `정답`보다는 `비교할 전문가 판단`으로 표현합니다.

상세 설계: [`docs/PRODUCT_DESIGN.md`](docs/PRODUCT_DESIGN.md)

## 출처 계보

Moon Survival 활동에는 여러 변형이 있습니다.

- Hall & Watson (1970) Survival Task의 고전 200-mile / 15-item 계열
- NASA/GSFC StarChild `Problems in Space` 및 `Experts' Solution`
- NASA의 후대 교육용 Survival 변형

이 프로젝트는 출처와 변형을 섞어 하나의 원작처럼 표현하지 않는 것을 원칙으로 합니다. 현재 시나리오는 고전 200-mile 계열을 중심으로 하고, 전문가 비교 순위와 설명은 NASA/GSFC StarChild 자료를 주요 기준으로 삼습니다.
